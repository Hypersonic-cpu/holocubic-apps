# Plan: Clocteck Themed WiFi Setup App

## 1. 目标

基于 `holocubic-apps/wifi_guide` 复制并开发独立应用 `wifi_guide_themed`，使用用户提供的背景图片实现新的配网界面。

**原则：只修改 UI，不重写配网逻辑，不修改原 App 和 Firmware。**

## 2. 项目结构

```text
wifi_guide_themed/
└── package/
    ├── app.info
    ├── config.json
    ├── main.lua
    ├── main.png
    ├── font/
    │   ├── msyh_cn_13.bin
    │   └── 18chinese.bin
    └── assets/
        ├── setup.jpg
        └── success.jpg
```

启动时先以黑底白字展示 `config.json` 中的问候语，持续 3 秒后进入配网状态。`greeting_day` 默认是 `Bonjour, B-cyt`，`greeting_night` 默认是 `Bonsoir, B-cyt`；按设备本地时间 06:00–17:59 / 18:00–05:59 选择。配置缺失、无效或对应文案为空时使用该时段的默认文本；无法读取有效时间时使用白天文案。

- 复制原 `wifi_guide` 项目作为基础。
- 修改 `app.info`，确保新旧 App 可以同时安装。
- 所有新资源路径使用 `/sd/apps/wifi_guide_themed/`。
- 保持 `/sd/apps/settings.json` 等系统公共路径不变。
- 按设备设置将 Launcher 自启动 App 指向 `wifi_guide_themed`；不修改 Launcher 或 Firmware 代码。

## 3. 背景图片要求

用户自行提供两张已经处理好的 **320×240（4:3）PNG 或 JPEG**：

| 文件 | 页面 |
|---|---|
| `assets/setup.jpg` | 等待配网 |
| `assets/success.jpg` | 配网成功 |

使用 PNG 时，对应调整扩展名和加载路径。

要求：

- 不允许程序自动裁剪、缩放、重新编码或修改背景。
- 不编写图片转换脚本。
- 背景包含人物、固定标题、装饰及四条空白信息栏。
- 四条信息栏的标签和数值均由 LVGL 动态绘制。
- 优先使用已确认支持的 JPEG；PNG 需先验证设备固件能否解码。
- 背景缺失或无法加载时，应显示简易备用界面，不能影响配网。
- 后续更换背景，只需替换对应图片文件。

## 4. 页面实现

### A. 等待配网：`setup.jpg`

| 行 | 标签 | 动态内容 |
|---|---|---|
| 1 | AP | 设备热点 SSID |
| 2 | 地址 | `192.168.18.1`（沿用现有配置） |
| 3 | 步骤1 | 连接设备热点 |
| 4 | 步骤2 | 浏览器打开配网地址 |

### B. 配网成功：`success.jpg`

| 行 | 标签 | 动态内容 |
|---|---|---|
| 1 | WiFi | 当前 SSID |
| 2 | 信号 | 信号柱及 RSSI（dBm） |
| 3 | IP | 当前 STA IPv4 地址 |
| 4 | 域名 | `clocteck-cubic.local` |

两页的标签、数值均由 LVGL 绘制，背景标题不重复绘制。

所有字体和控件坐标必须根据 320×240 背景准确标定。特别处理长 SSID、字体缺字及文字溢出，不得覆盖人物。

### C. USB 串口配网

保留原有独立串口配网页面，暂不重新设计，也不增加第三张背景。

## 5. 实现步骤

### Step 1：复制项目

- 复制 `wifi_guide` 为 `wifi_guide_themed`。
- 修改 `app.info` 和应用专属资源路径。
- 保证新旧应用可以独立运行。

### Step 2：实现背景与前景

- 使用 `lv_img_create()`、`lv_img_set_src()` 加载背景。
- 使用 `lv_label_create()` 绘制动态文字。
- 保留现有信号强度柱的绘制逻辑。
- 复用现有字体加载和资源释放机制。
- 避免在内存中同时保留不必要的全屏图片。
- 集中定义页面坐标和字体配置，方便以后调整。

### Step 3：适配状态切换

复用现有：

- `build_setup_ui()`
- `build_success_ui()`
- `show_setup()`
- `show_success()`
- `check_state()`

可以重构这些函数的 UI 部分，但不得破坏网络检测及状态切换行为。

联网成功自动显示成功页；断开连接后自动显示等待配网页。

### Step 4：保留原配网功能

以下功能必须保持兼容：

- AP 热点及 HTTP 配网。
- USB UART 配网与 `@CUBIC_WIFI/1` 协议。
- WiFi 扫描、鉴权、连接及错误处理。
- SSID、RSSI、IP 的实时更新。
- 中英文设置对其他页面的影响。
- HOME 退出及资源清理。

不得随意修改 PCAPP 依赖的 UART 消息字段，包括 `app = "wifi_guide"`。

### Step 5：启动动画预留

未来可支持：

`进入 App → 播放 Hello GIF → 检查网络状态 → 进入对应配网页面`

本次不实现动画，不生成 GIF，只确保后续容易扩展。

## 6. 验收标准

- 原版 `wifi_guide` 不受影响。
- 新旧 App 可以同时安装和运行。
- 两张背景正确显示，严格 320×240。
- 不改变背景视觉内容。
- 四条信息栏文字、数值与背景正确对齐。
- 无乱码、重叠、越界或人物遮挡。
- 首次配网、断线重连、USB 串口配网正常。
- HOME 正常退出。
- 无明显内存泄漏或定时器残留。
- 替换同名背景图片后，无需修改 Lua 即可更新视觉效果。
